# Framosaic

Framosaic turns a photo into a grid of tiles sized for instant-film formats
(Polaroid, Instax, and others), so you can print each tile and reassemble
them into a wall mosaic. Everything runs client-side — your photo never
leaves your browser.

> **Status:** under active development. This README will grow with setup,
> usage, and calibration instructions as the app takes shape.

## Development

```bash
npm install
npm run dev
```
